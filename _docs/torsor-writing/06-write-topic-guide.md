for when the sources are many, large, or scanned without a text layer, and what we want is one guide rather than a companion to any single paper.

## invoke

```
/write-topic-guide
```

## produces

a document in the torsor house format: LaTeX source, plus PDF, HTML, EPUB, and
Markdown built from it.
