Working material for someone assessing a paper: a summary of the work, a graded issue list, suggested repairs, and annotated copies of the paper's own source. Runs unattended and reaches no verdict.

## Invoke

```
/write-critical-guide
```

## Produces

A document in the torsor house format: LaTeX source, plus PDF, HTML, EPUB, and
Markdown built from it.
