For when the sources are many, large, or scanned without a text layer, and what's wanted is one guide rather than a companion to any single paper.

## Invoke

```
/write-topic-guide
```

## Produces

A document in the torsor house format: LaTeX source, plus PDF, HTML, EPUB, and
Markdown built from it.
